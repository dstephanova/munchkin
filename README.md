# Munchkin 🐱

A cute food diary. Snap or type what you ate, Munchkin (using your own free Gemini key) guesses the calories and macros, and you fix anything by chatting. Each meal keeps its own chat.

- Log in with Google; each person's diary is private (Firebase).
- Gemini key stays on each person's own device.
- Add `?demo` to the address to try it with pretend data and pretend answers.
